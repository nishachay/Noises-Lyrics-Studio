# Noises Lyrics Studio (v3)

Welcome to Noises Lyrics Studio, a premium and lightning fast tool designed for creating cinematic, perfectly synced lyric videos directly in your browser. Whether you want to render a full track for YouTube, generate a 30 second Short for TikTok and Instagram, or export a minimalist slideshow presentation, Noises Lyrics Studio makes it incredibly simple.

## Key Features

* **Instant YouTube Music Integration:** Just paste any YouTube URL or search for a song. The tool bypasses throttling and blocks, securely fetching the highest quality audio directly to your local machine for instant playback and rendering.
* **Auto Sync and Translations:** Automatically pulls time stamped lyrics and translates them on the fly. 
* **Manual Tap Sync:** A beautifully redesigned, distraction free Tap Sync mode. Just listen to the song and tap the spacebar to lock in the perfect timing for every single line.
* **Intelligent Backgrounds:** If a song has an official album cover, it will fetch a gorgeous 3000x3000px high resolution image from iTunes and use it. If not, it generates a beautiful, randomized dark gradient mesh.
* **Multiple Export Formats:**
  * **Full Video:** Renders a gorgeous 1080p or 720p 60fps lyric video.
  * **Shorts / Reels:** Select any part of the song and instantly export a vertical 9:16 Short.
  * **Slideshows:** Select specific lyric lines to export as a zip file containing high resolution presentation slides.
* **Zero Dependencies Required for Users:** Runs entirely locally with an integrated web interface.

## How to Start and Use the Tool

I have included a simple batch file to make launching the tool as easy as clicking a single button.

1. Open the project folder on your computer.
2. Double click the file named **`Start_Noises_Studio.bat`**.
3. A command prompt window will open and start the local server.
4. Your default web browser will automatically open to `http://localhost:3000` where the studio is ready to use!

## Example Outputs

When you export a video, the tool will automatically format the output file with clean naming conventions, for example:
* `The Weeknd - Starboy_1781529982.mp4` (Full Video)
* `The Weeknd - Starboy_1781529982_short.mp4` (Vertical Short)
* `The Weeknd - Starboy_1781529982_slideshow.zip` (Image Slideshow)

Along with your render, the tool will also generate:
* **Thumbnail Image:** A ready to upload high resolution thumbnail.
* **SEO Metadata:** A text file packed with auto generated tags, a formatted description with copyright disclaimers, and the full text lyrics for you to copy and paste into YouTube.

Enjoy creating!

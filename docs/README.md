# docs/

Screenshots and short clips referenced by the README live here.

- Add a screen recording at **`docs/demo.gif`** (the README embeds it).
- Add any extra screenshots as `docs/*.png` / `docs/*.jpg`.

Media rules for this folder:

- Keep files small (GIFs under a few MB).
- Only add media you have the rights to use.
- Do **not** add audio or full videos here — `*.mp3`, `*.mp4`, `*.webm` etc. are
  gitignored on purpose.
